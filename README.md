# إتقان — منصة كورسات أونلاين (Frontend)

موقع فرونت إند كامل (HTML / CSS / JavaScript خالص) لمنصة بيع كورسات أونلاين باللغة العربية (RTL).

## المعاينة المباشرة
بعد تفعيل GitHub Pages على فرع `main`، الموقع بيكون متاح على:
`https://<username>.github.io/<repo-name>/`

وللتجربة محليًا، افتح `index.html` مباشرة في المتصفح، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## المميزات
- تصميم عصري متجاوب (موبايل / تابلت / ديسكتوب) بدون أي مكتبات خارجية
- هيدر ثابت مع تأثير Blur وقائمة موبايل منسدلة
- فلترة الكورسات حسب التصنيف (برمجة / تصميم / تسويق / بيزنس)
- سلة مشتريات بعداد وإشعارات Toast
- عدادات إحصائيات متحركة وأنيميشن عند التمرير (Scroll Reveal)
- أقسام: Hero، تصنيفات، كورسات، مميزات، باقات أسعار، آراء طلاب، أسئلة شائعة، دعوة للتسجيل، فوتر
- احترام `prefers-reduced-motion` لتقليل الحركة

## هيكل المشروع
```
courses-site/
├── index.html      # الصفحة الرئيسية
├── css/
│   └── style.css   # كل التنسيقات
└── js/
    └── script.js   # التفاعلات (قائمة، فلاتر، سلة، أنيميشن)
```
